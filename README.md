# 《读者 200 期》文本

这里收录了《读者》杂志2000年以前的全部文本，从1981年第1期到1999年第12期，共11000多篇文章，总计约1300余万字。
这些文本来自于《读者》杂志社发行的三张光盘：《读者 200 期》金盘、《读者’98电子版》、《读者’99电子版》。

在线浏览文章： https://duzhe200.appspot.com

《读者》1981年4月创刊（当时叫《读者文摘》，1993年7月改为《读者》），一开始是双月刊，1981年共出版了5期；从1982年起改为月刊，每年发行12期，1998年第3期正好是总第200期（5 + 12 * (1998-1982) + 3 = 200）。1998年5月《读者》杂志社发行了《读者 200 期》光盘电子版，收录了一共9953篇文章。

《读者 200 期》光盘的数据有以下问题：
  * 缺了1982年第2期和1986年第2期，实际上只有198期。
  * 平均每期有 9953 / 198 ~= 50 篇文章，但是1983.3、1983.11、1997.10这几期的文章数加起来不足10篇，明显偏少。
  * 平均每期约有6万字内容，但1983.10这期有12万字，怀疑是将1983.11期大部分文章误标为1983.10期。

加上1998年和1999年的光盘电子版里的24期文章，去掉1998年重复的前3期（duzhe200.yaml中标为 skip: 1），这里一共收录了 198 + 24 - 3 = 219 期全文。

此处收录的最后一期是《读者》1999年第12期（总第221期），杂志自2000年起改为半月刊，每年发行24期，这里没有收录2000年以后的文章。
